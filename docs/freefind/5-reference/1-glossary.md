# Glossary -- FreeFind.com

Glossary

This handy glossary defines some terminology your may have encountered while using this search engine. Choose a term listed below for its definition:

[admin](#admin)

**Definition:** Short for "administration". The Control Center page which allows you to change your basic account information (_i.e._ web site address, email address, password).

From [Glossary](https://freefind.com/library/ref/glossary/index.html)

[Control Center](#ControlCenter)

**Definition:** The part of the FreeFind web site used to manage your FreeFind account. It is located [here](https://freefind.com/control.html).

From [Glossary](https://freefind.com/library/ref/glossary/index.html)

[DataSearch](#DataSearch)

**Definition:** The search engine mode which allows you to search "lists of things" instead of searching pages. When using DataSearch, the search results show a custom list of the actual items searched for, as opposed to the usual list of links to pages.

From [Glossary](https://freefind.com/library/ref/glossary/index.html)

[FAQ](#FAQ)

**Definition:** Short for "frequently asked questions". A list of common questions and their answers. It is located [here](https://freefind.com/library/ref/faq/).

From [Glossary](https://freefind.com/library/ref/glossary/index.html)

[HTML](#HTML)

**Definition:** Short for "hyper-text markup language". This is the underlying computer language that web pages are written in. To see what it looks like, use the "view source" option on your browser now.

From [Glossary](https://freefind.com/library/ref/glossary/index.html)

[implement](#implement)

**Definition:** To create.

From [Glossary](https://freefind.com/library/ref/glossary/index.html)

[index](#index)

**Definition:** _Noun:_ A table of all the words in your site and which pages they occur on.  
_Verb:_ To create such an index.

From [Glossary](https://freefind.com/library/ref/glossary/index.html)

[indexer](#indexer)

**Definition:** Software running on our computers which automatically "browses" a web site in order to determine which pages belong to that site and which words to index on each page. After determining this, the software then builds an index for that site.  
_Synonym:_ Spider

From [Glossary](https://freefind.com/library/ref/glossary/index.html)

[keyword](#keyword)

**Definition:** _1:_ Word that is being searched for. _2:_ Word that describes a page.

From [Glossary](https://freefind.com/library/ref/glossary/index.html)

[mode](#mode)

**Definition:** An overall way of operating. This search engine can operate in the typical page search mode, or it can operate in DataSearch mode.  
**See Also:** [DataSearch](https://freefind.com/library/ref/glossary/#DataSearch), [Page Search](https://freefind.com/library/ref/glossary/#pagesearch)

From [Glossary](https://freefind.com/library/ref/glossary/index.html)

[page search](#pagesearch)

**Definition:** The search engine mode which allows you to search for pages using keywords. When used in this mode the search engine will display a list of links to the pages which contain the desired keywords. This is the traditional operating mode of search engines.

From [Glossary](https://freefind.com/library/ref/glossary/index.html)

[publish](#publish)

**Definition:** To update your web site with new and/or modified pages.

From [Glossary](https://freefind.com/library/ref/glossary/index.html)

[query](#query)

**Definition:** _Noun:_ The keywords being searched for.  
_Verb:_ To search using those keywords.

From [Glossary](https://freefind.com/library/ref/glossary/index.html)

[remotely-hosted](#remotelyhosted)

**Definition:** Implementing a web site service or feature using web servers external to your own. This search engine is remotely-hosted. It implements a search feature for your web site using our servers, which are external and separate from your web site server.

From [Glossary](https://freefind.com/library/ref/glossary/index.html)

[robot](#robot)

**Definition:** Software running on an external computer which automatically "browses" the web, processing the pages it finds as it goes.  
**See Also:** [Spider](https://freefind.com/library/ref/glossary/#spider)

From [Glossary](https://freefind.com/library/ref/glossary/index.html)

[search box](#searchbox)

**Definition:** In a web site page, the field a user enters their search query into.  
_Synonym:_ Search Panel

From [Glossary](https://freefind.com/library/ref/glossary/index.html)

[search panel](#searchpanel)

**Definition:** In a web site page, the field a user enters their search query into.  
_Synonym:_ Search Box

From [Glossary](https://freefind.com/library/ref/glossary/index.html)

[search results](#searchresults)

**Definition:** The page displayed as a result of a visitor to your web site performing a search query. Usually, this is the typical list of pages found which contain the query keywords. It may also refer to the site map, what's new listing, or other pages generated as a result of the query.

From [Glossary](https://freefind.com/library/ref/glossary/index.html)

[section](#section)

**Definition:** Part of your site which users may search separately from other parts of your site. For more information see [How to Use Sections](https://freefind.com/library/howto/sections/).

From [Glossary](https://freefind.com/library/ref/glossary/index.html)

[server](#server)

**Definition:** A computer which implements a web site or web service.

From [Glossary](https://freefind.com/library/ref/glossary/index.html)

[site ID](#siteid)

**Definition:** A text string which uniquely identifies a search engine account.

From [Glossary](https://freefind.com/library/ref/glossary/index.html)

[site map](#sitemap)

**Definition:** A web page generated by the search engine which shows an overview of your site. For large sites the site map does not show every page, just the major sections of the site. It is a type of search result.

From [Glossary](https://freefind.com/library/ref/glossary/index.html)

[site search](#sitesearch)

**Definition:** A search engine which just searches a single site for pages matching a search query.

From [Glossary](https://freefind.com/library/ref/glossary/index.html)

[spider](#spider)

**Definition:** Software running on our computers which automatically "browses" a web site in order to determine which pages belong to that site and which words to index on each page. After determining this, the software then builds an index for that site.  
_Synonym:_ Indexer

From [Glossary](https://freefind.com/library/ref/glossary/index.html)

[string](#string)

**Definition:** Text. One or more words in a row. This definition is a string.

From [Glossary](https://freefind.com/library/ref/glossary/index.html)

[template](#template)

**Definition:** A web page of your design into which the search results are inserted before the page is displayed to your users. For more information see [Using Templates for the Best Look](https://freefind.com/library/howto/templates/).

From [Glossary](https://freefind.com/library/ref/glossary/index.html)

[upload](#upload)

**Definition:** To copy a file from the computer you are currently using to our servers.

From [Glossary](https://freefind.com/library/ref/glossary/index.html)

[URL](#URL)

**Definition:** A web address. This may be the address of a page of your web site or part of a page, like an image.

From [Glossary](https://freefind.com/library/ref/glossary/index.html)

[what's new listing](#whatsnewlisting)

**Definition:** A web site page generated by the search engine which lists the most recently modified pages of your site. It is a type of search result.

From [Glossary](https://freefind.com/library/ref/glossary/index.html)

[web search](#websearch)

**Definition:** A search engine which searches the entire web for pages matching a search query. A web search engine rarely lists pages from your site simply because it is choosing from the many millions of pages that are on the web.

From [Glossary](https://freefind.com/library/ref/glossary/index.html)
