# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public GitHub issue. Email [oliver@oliverearl.co.uk](mailto:oliver@oliverearl.co.uk) with the subject line `FreeFind Laravel security report` and include:

- the affected package version or commit;
- a minimal reproduction and the security impact; and
- any suggested mitigation, if available.

Do not include credentials, authentication headers, private site content, or unnecessary raw FreeFind queries/results. If a proof of concept must contain sensitive data, describe how to provide it safely instead of sending it in the first message.

## Support status

The repository is pre-release and has no supported package version yet. Reports against the current `main` branch are welcome. Once `1.0.0` is released, supported versions will be listed here.

## Scope

This policy covers vulnerabilities in this repository’s code, configuration, workflows, and published package artifacts. It does not cover FreeFind’s hosted service, Control Center, account systems, infrastructure, or other third-party services. Report a suspected FreeFind service vulnerability to FreeFind through its own support/security channels as well as following its current terms.
